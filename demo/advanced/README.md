# 🚀 Advanced Demos - Surface Cutting Optimizer

Esta carpeta contiene **demos avanzados** que muestran las características más sofisticadas y mejoras de rendimiento de la librería Surface Cutting Optimizer.

## 📋 Demos Disponibles

### `impact_analysis_demo.py`
**🔍 Análisis de Impacto de Mejoras**
- Compara el rendimiento antes vs después de las optimizaciones
- Muestra mejoras de +34.2% en eficiencia y 263x más rápido
- Analiza todos los modos de prioridad automática
- **Resultados**: Demuestra mejoras dramáticas en eficiencia

### `hybrid_optimization_demo.py` (próximamente)
**🤖 Optimización Multi-Algoritmo**
- Ejecuta múltiples algoritmos concurrentemente
- Selección inteligente del mejor resultado
- Comparación de rendimiento algoritmo por algoritmo

## 🎯 Propósito de los Demos Avanzados

Los demos avanzados están diseñados para:

1. **📊 Análisis de Rendimiento**: Medir y documentar mejoras de la librería
2. **🔬 Investigación**: Comparar algoritmos y estrategias de optimización  
3. **🚀 Características Avanzadas**: Mostrar funcionalidades profesionales
4. **📈 Benchmarking**: Evaluar rendimiento en casos complejos

## 🆚 Diferencia con Demos Básicos

| Aspecto | Demos Básicos (`/demo`) | Demos Avanzados (`/demo/advanced`) |
|---------|-------------------------|-------------------------------------|
| **Objetivo** | Aprendizaje básico | Análisis profesional |
| **Complejidad** | Simple, paso a paso | Análisis completo |
| **Audiencia** | Nuevos usuarios | Desarrolladores, investigadores |
| **Datos** | Casos simples | Problemas complejos |
| **Salida** | Resultados básicos | Métricas detalladas, comparaciones |

## 🏃‍♂️ Cómo Ejecutar

```bash
# Desde la raíz del proyecto
cd demo/advanced

# Ejecutar análisis de impacto
python impact_analysis_demo.py

# Ver resultados guardados

```
